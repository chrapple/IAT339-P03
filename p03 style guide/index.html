Numbered Lists

CSS selector:

ol, li

Sample code:

<ol><li>item 1</li><li>item 2</li><li>item 3</li></ol>

  2. item 2
  3. item 3

Unordered Lists

CSS selector:

ul, li

Sample code:

  • item 2
  • item 3
